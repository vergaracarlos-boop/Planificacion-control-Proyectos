Planificación y Control de Proyectos

Clase 2, Semana 8

01. Introducción

Gestión de Proyectos con Software

  • Optimiza recursos y reduce tiempos de ejecución.
  • Facilita el cálculo automático de la ruta crítica.
  • Centraliza la información de costos y plazos.
  • Permite escenarios dinámicos ante cambios imprevistos.
[Imagen conceptual: Carta Gantt o Plano]
02. Herramienta

¿Qué es ProjectLibre?

[Captura de pantalla de ProjectLibre]
  • Alternativa Open Source líder mundial a MS Project.
  • Creación estructurada de Cartas Gantt y WBS.
  • Compatibilidad bidireccional con archivos de Microsoft.
  • Control riguroso de costos mediante Valor Ganado.

04. Procedimiento

Descarga Segura del Software

  • Ingresa al enlace verificado de SourceForge.
  • Haz clic en el botón verde "Download Latest Version".
  • Espera 5 segundos sin hacer clic en publicidad.
  • Guarda el instalador en tu carpeta "Descargas".
04. Procedimiento

Instalación Paso a Paso en Windows

[Captura: Asistente de instalación .exe]
  • Ejecuta el archivo descargado .exe.
  • Otorga permisos de administrador si el sistema lo requiere.
  • Acepta los términos de la licencia pública.
  • Completa el asistente haciendo clic en "Next".
04. Procedimiento

Configuración Inicial Lista

  • Inicia ProjectLibre desde el menú principal.
  • Acepta la validación del correo electrónico (opcional).
  • Selecciona el idioma español en configuraciones si es necesario.
  • El área de trabajo debe mostrar un diagrama Gantt vacío.

05. Caso de Estudio

Proyecto: Radier Base

Definición de Datos

Nombre: Radier Base Sector A

Inicio: Próximo lunes hábil

Gerente: Tu nombre completo

  • Ingresa los datos definidos en el recuadro.

06. Evaluación

Rúbrica de Desempeño

Escala Criterio de Desempeño Operativo
Excelente Software instalado. Proyecto creado con 2 tareas vinculadas correctamente.
Satisfactorio Software instalado. Proyecto creado pero existen errores en la vinculación.
Insuficiente No logró instalar el software o no pudo crear el proyecto base.
